# Repositorio base del curso

Ejemplo completo y funcional con la clínica veterinaria de la presentación. Clónalo para comprobar tu instalación y para guiarte al hacer tus tareas.

- **Tarea 3:** la base de datos de la clínica (`db/` y `tests.sql`).
- **Tarea 4:** la recepción publica en Kafka la llegada de cada mascota (`app_simulator/`), y la ingesta guarda los mensajes en un crudo y los procesa (`ingestion/`).

**Tus tareas no se hacen aquí:** van en tu propio repositorio, independiente de este. Las instrucciones están en el enunciado de cada tarea.
